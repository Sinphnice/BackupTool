# BackupTool

BackupTool 是《软件开发综合实验》课程项目，目标是设计并实现一款基本可用的数据备份软件。项目围绕软件工程完整流程推进，包括需求分析、系统设计、编码实现、软件测试和成果展示。

## 项目目标

- 将指定目录树中的文件数据备份到目标位置。
- 将备份数据还原到指定目录。
- 保证备份与还原过程的正确性、易用性和健壮性。
- 配套完成课程要求的需求分析说明书、系统设计文档和软件测试报告。

## 当前架构

当前项目采用纯 Rust 后端：

```text
TypeScript GUI -> Tauri command -> Rust backup-core
```

| 部分 | 目录 | 技术 | 作用 |
| --- | --- | --- | --- |
| 前端界面 | `src/` | TypeScript, Vite | 构建 Web UI，并通过 Tauri API 调用后端命令 |
| 桌面壳与命令层 | `src-tauri/` | Rust, Tauri 2 | 提供桌面窗口和 Tauri command，只做 DTO 转换 |
| 备份核心库 | `crates/backup-core/` | Rust | 实现备份、恢复、筛选和后续仓库式备份核心逻辑 |

当前功能为 legacy mirror backup：将普通目录中的普通文件按相对路径复制到备份目录，并可从备份目录恢复到指定目录。该能力作为基础验收和后续仓库式备份演进的兼容基线。

## 基础功能

根据课程要求，本项目至少需要实现以下基础功能：

1. 数据备份：遍历源目录树，将文件数据保存到指定备份位置。
2. 数据还原：读取备份数据，将目录树和文件内容恢复到指定位置。

当前已支持：

- 普通目录和普通文件的备份与恢复。
- 目标目录不存在时自动创建。
- 路径、扩展名、文件名、修改时间、文件大小筛选。
- Tauri GUI 触发备份、恢复并显示结果。

## 可选扩展方向

项目可根据开发进度选择实现以下扩展功能：

- 仓库式备份：使用 repository、snapshot、manifest、object store 管理多次备份。
- 文件元数据支持：保存并恢复文件时间、权限、属主等信息。
- 文件类型支持：支持特定文件系统的特殊文件，例如链接、管道、设备文件。
- 打包与解包：将备份仓库或快照组织为单个备份包。
- 压缩与解压：减少备份数据占用的存储空间。
- 加密与解密：使用用户指定密码保护备份数据。
- 图形界面：提供友好易用的 GUI 操作界面。
- 定时备份：支持周期性备份和旧备份清理。
- 实时备份：监听文件变化并自动触发备份。
- 网络备份：扩展为支持远程存储或网盘模式。

## 构建与运行

详细的环境配置、依赖检查和构建流程见 [开发环境与构建说明](docs/DEVELOPMENT.md)。

首次配置：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap-windows.ps1
just setup
```

常用命令：

```bash
just check
just test
just dev
```

完整 release 构建：

```bash
just build
```

构建成功后，可执行程序位于：

```text
src-tauri/target/release/backup-tool.exe
```
